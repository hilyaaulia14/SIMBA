# SIMBA (Sistem Informasi Balai Pemasyarakatan)
**Balai Pemasyarakatan (Bapas) Kelas I Banjarmasin**

Sistem informasi berbasis website untuk digitalisasi tata kelola administrasi perkantoran dan pembimbingan klien pemasyarakatan:
1. Pencatatan dan Pengarsipan Digital Surat Masuk & Surat Keluar (Bagian Umum)
2. Pengelolaan Data Klien Pemasyarakatan (Pembimbing Kemasyarakatan)
3. Pengaturan Ketersediaan Jadwal Bimbingan (Atur Jadwal PK)
4. Manajemen Penjadwalan Bimbingan Klien
5. Pencatatan Bukti Kehadiran dan Evaluasi Perkembangan Klien (Presensi Wajib Lapor)
